# Snake

A minimal classic Snake game built with vanilla HTML, CSS, and JavaScript.

## Run locally

You can open `index.html` directly in a browser, or serve it locally:

```bash
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.

## Manual verification checklist

- Move the snake with arrow keys/WASD and on-screen buttons.
- Eat food to grow and increase the score.
- Verify the game ends on wall/self collision and restart works.
- Blur the tab/window and confirm the game pauses.
